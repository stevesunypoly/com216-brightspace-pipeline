Class Workbench

This class itself is built the same way your own workbench is: as a folder a model can be pointed at. The shared Class Workbench holds the Zotero bibliographies, the transcripts of conversations used to generate and manage the class, and the artifacts — all the conversations and tasks — used to build it. If you want the model to reason over the actual material behind this course, not just what you've been told about it, this is that material.

1. Open the shared folder

Go to the shared Google Drive folder 555-class-workbench

2. Download it as a zip

Click the folder name 555-class-workbench, then select Download. Google Drive generates a zip file of the entire workbench automatically.

https://drive.google.com/drive/folders/14Mp2hA0Q_KR1Rc_-AY7p0ZOgIHOG4OyU

3. Upload it to Claude

Upload that zip file to Claude to bring the full class context — bibliographies, transcripts, and artifacts — into your session.
