Welcome — Your Workbench, and This One

Every turn you do in this course produces a document, and every document goes into a folder: your workbench. It starts nearly empty in week one and it is still growing in week fifteen. Full setup for it is in the Toolkit module — this is just the idea, before you build it.

Here is the part that is easy to miss: the course itself is set up the same way. This whole class (the cuboid, the case list, the readings, the turn templates) lives in a folder too, and you can see it here:

https://drive.google.com/drive/folders/1eaoDlmbR3k6QIwenL8WUilrlA-L6ZMLL?usp=sharing (external site)

That folder is not just a place to browse. It is a workbench a model can read. Point an LLM at it, hand it files from that folder or describe what is in it, and the model can reason over the actual material of the course, not a summary of it. Your own workbench works the same way: a folder built to be fed to a model and inferred against, turn after turn.

Full setup, tool list, and folder structure are in the Toolkit module. Start there before Assignment 1.
