Toolkit

This class relies on students having access to a specific set of tools in order to fully participate in the class. We have resources to provide support should you find this challenging.

The class assumes you run the Chrome browser, which is officially the only browser SUNY Poly supports. (I believe all of our tools work with Edge, but may not with Firefox or Safari.)

We ask that you install a Chrome browser extension that will allow you to capture archives of your LLM conversations.

We ask that you install Zotero, a bibliographic management system, and its companion Chrome browser extension, which will allow you to identify, capture, and ingest bibliographic sources.

Finally, we ask that you download the Claude Desktop application for use during the class.

Install steps for each of these live in the Toolkit module. See also: Microsoft Teams, your workbench, the Class Workbench, and the Claude Account & Acceptable Use Policy.
