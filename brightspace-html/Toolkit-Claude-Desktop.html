Setup

  1. Run the installer for your OS.
  2. Sign in with the same Claude account used everywhere else — conversations, projects, and memory sync across desktop, web, and mobile once signed in.
Cowork mode requires the desktop app running on a computer that isn't asleep — it can't complete tasks while your machine is off or sleeping.
