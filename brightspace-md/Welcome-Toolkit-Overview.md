This class relies on students having access to a specific set of tools
in order to fully participate in the class. We have resources to provide
support should you find this challenging.

The class assumes you run the [Chrome browser](Toolkit-Chrome.html),
which is officially the only browser SUNY Poly supports. (I believe all
of our tools work with Edge, but may not with Firefox or Safari.)

We ask that you install a [Chrome browser
extension](Toolkit-Exporter-Install.html) that will allow you to capture
archives of your LLM conversations.

We ask that you install [Zotero](Toolkit-Zotero.html), a bibliographic
management system, and its companion Chrome browser extension, which
will allow you to identify, capture, and ingest bibliographic sources.

Finally, we ask that you download the [Claude
Desktop](Toolkit-Claude-Desktop.html) application for use during the
class.

Install steps for each of these live in the Toolkit module. See also:
[Microsoft Teams](Toolkit-Teams.html), your
[workbench](Toolkit-Workbench.html), the [Class
Workbench](Toolkit-Class-Workbench.html), and the [Claude Account &
Acceptable Use Policy](Claude-Acceptable-Use-Policy.html).
